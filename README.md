# Coffee Shop Sales Analysis – Power BI

## Project Overview

An interactive Power BI dashboard developed to analyse coffee shop sales performance, customer purchasing patterns, and key business trends.

## Key KPIs

* **Total Revenue**
* **Total Orders**
* **Total Quantity Sold**
* **Average Revenue per Order**
* **Average Selling Price**

## Key Business Insights

* Identified the **best-performing store** and analysed **store contribution to total revenue**.
* Analysed **highest-selling products** and product/category performance.
* Tracked **Month-over-Month (MoM) sales growth**.
* Analysed **Month-to-Date (MTD) sales performance**.
* Identified the **best sales day** and **peak sales hour**.
* Analysed sales trends across **products, categories, stores, and time periods**.

## Tools Used

**Power BI | Power Query | DAX**

## Outcome

Built an interactive dashboard to monitor sales performance, identify key trends, and generate actionable business insights for data-driven decision-making.
